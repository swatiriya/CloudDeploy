# CloudDeploy

### Self-Service Infrastructure Provisioning and Application Deployment Platform

CloudDeploy is a DevOps automation project that allows developers to create, configure, manage, and destroy cloud-based development and testing environments through a web dashboard.

Instead of manually creating servers and installing software, developers can request an environment through the portal.

## Technology Stack

- React.js – Frontend
- Node.js and Express.js – Backend
- MongoDB – Database
- Terraform – Infrastructure as Code
- Ansible – Configuration Management
- AWS – Cloud Infrastructure
- Git and GitHub – Version Control

## Key Features

- Create development and testing environments.
- Automatically provision infrastructure using Terraform.
- Configure servers using Ansible.
- Deploy applications automatically.
- Track environment status and ownership.
- Maintain deployment history.
- Estimate infrastructure costs.
- Destroy unused environments.

## Project Status

Currently under development.

## Project Structure

- `frontend/` – React dashboard
- `backend/` – Node.js and Express APIs
- `infrastructure/` – Terraform configurations
- `configuration/` – Ansible playbooks
- `docs/` – Project documentation

## Objective

To simplify cloud infrastructure management through self-service automation and demonstrate practical DevOps concepts.
